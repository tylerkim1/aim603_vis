# 내 그림은 어디에 가까울까요? — KAIST Visualization Project

브라우저에서 그림을 그리면 CLIP이 40개 후보 문장과의 유사도를 계산합니다. 소개 화면과 실제 그리기 화면에 임베딩 지도를 제공합니다.

## 실행

프로젝트 폴더에서 `npm start` 후 http://localhost:8080 으로 접속합니다. 최초 실행에는 모델·라이브러리 다운로드를 위한 인터넷이 필요합니다. 모든 그림 분석은 브라우저 안에서 실행됩니다.

## 시각화

- 소개: 실제 모델로 계산한 집·나무·고양이 자동 생성 스케치. 예시 전환 시 위치, cosine 순위, 각도와 상대 점수가 함께 바뀝니다.
- 지도: 그림 중심 유사도 비교입니다. PCA 투영 대신 실제 cosine이 클수록 중심에 가까운 반지름을 사용합니다. r = 52 + 100 × (최대 cosine − 후보 cosine) / (최대 cosine − 최소 cosine). 후보 내 상대 범위를 확대하므로 그림 간 절대 거리 비교에는 쓰지 않습니다. 동점은 같은 반지름이며 모든 점수가 같으면 중간 반지름을 씁니다.
- 주황 점: 그림. 청록 연결선: 원래 512차원 cosine 1위. 옅은 연결선: 2·3위. 파란 테두리: 선택한 목표 단어.
- 화면에서 그림 중심까지의 거리 순서는 실제 cosine 순위와 일치합니다. 방향은 후보를 펼치기 위한 배치일 뿐이며 단어끼리의 거리는 의미하지 않습니다. 512차원 공간 전체를 2차원으로 복원한 그림이 아닙니다.
- 단어 선택: 해당 단어와 가장 가까운 다른 단어 3개를 원래 벡터로 계산해 표시합니다.
- 각도 도식: 선택한 그림·문장 사이의 실제 각도를 별도로 표시합니다. 지도상의 각도를 사용하지 않습니다.
- 움직임: 스케치 순차 그리기, 후보의 방사형 등장, 각도 전환, 막대 진입. 동작 줄이기 설정을 지원합니다.

## 점수 해석

`softmax(100 × cosine)`으로 후보 간 상대 점수를 계산합니다. 정답일 확률로 보정된 값이 아니며 후보 목록과 배율에 따라 달라집니다. 선 중요도는 선을 제거했을 때 1위 후보의 상대 점수 감소량입니다.

## 파일

| 파일 | 역할 |
|---|---|
| js/embedding-map.js | 그림 중심 상대 유사도 지도, 정확한 cosine 상위 후보 연결선 |
| js/map-data.js | 실제 q8 CLIP 문장 40개·예시 그림 3개의 벡터 |
| js/intro.js | 예시 전환과 지도·각도·상대 점수 연동 |
| js/app.js | 그리기, 추론, 지도 갱신, 결과와 선 중요도 |
| js/clip.js | 실제 CLIP 이미지·문장 임베딩과 cosine/softmax |
| tools/map-data.html | 모델로 지도 예시 데이터 계산 |
| tools/build-map-data.mjs | localhost:8080에서 계산 후 map-data.js 저장 |
| tools/verify-redesign.mjs | 브라우저 동작 검증과 스크린샷 저장 |

서버 실행 중 `node tools/build-map-data.mjs`로 실제 데이터를 재계산할 수 있습니다. 로컬 Chrome과 설치된 puppeteer-core를 사용합니다. 이전 intro-data.js와 precompute 도구는 이전 실험용 데이터로 보존하며 현재 소개 화면의 지도는 map-data.js를 사용합니다.

## 검증

실제 Chrome에서 예시 전환, 단어 클릭, 마우스 그리기, 목표 단어 비교, Undo, Clear(추론 중 포함), 완료·다시 그리기, 390px 가로 넘침과 동작 줄이기 설정을 확인했습니다. 측정 상세: screenshots/redesign-checks.json. WebGPU와 실제 터치 기기는 미검증입니다.
